第 6 章 · 项目二：图片书签社交网站

分享内容

这一章做出网站的核心玩法：用户在任何网站上点一下浏览器书签栏里的按钮，就能挑一张图片收藏到我们的站点。 我们会用到多对多关系、重写表单的 save()、JavaScript 书签小工具（bookmarklet）、缩略图， 以及用 fetch() 实现的“点赞不刷新”和“无限滚动”。

本章目标

  • 用 ManyToManyField 表示“用户点赞图片”
  • 在 clean_<field>() 中校验字段，重写 ModelForm.save() 下载远程图片
  • 理解 bookmarklet 的“启动器 + 远程脚本”结构
  • 用 easy-thumbnails 生成缩略图
  • 在 JavaScript 请求中携带 CSRF 令牌，返回 JsonResponse
  • 用同一个视图同时服务整页请求和“只要列表片段”的异步请求，实现无限滚动

Image 模型与多对多关系

from django.conf import settings
from django.db import models
from django.urls import reverse
from django.utils.text import slugify


class Image(models.Model):
    user = models.ForeignKey(settings.AUTH_USER_MODEL, related_name='images_created',
                             on_delete=models.CASCADE)
    title = models.CharField(max_length=200)
    slug = models.SlugField(max_length=200, blank=True)
    url = models.URLField(max_length=2000)                    # 原图地址
    image = models.ImageField(upload_to='images/%Y/%m/%d/')   # 下载到本站的文件
    description = models.TextField(blank=True)
    created = models.DateTimeField(auto_now_add=True)
    users_like = models.ManyToManyField(settings.AUTH_USER_MODEL,
                                        related_name='images_liked', blank=True)

    class Meta:
        indexes = [models.Index(fields=['-created'])]
        ordering = ['-created']

    def __str__(self):
        return self.title

    def save(self, *args, **kwargs):
        if not self.slug:
            self.slug = slugify(self.title)          # 自动生成 slug
        super().save(*args, **kwargs)

    def get_absolute_url(self):
        return reverse('images:detail', args=[self.id, self.slug])
ⓘ 同一张表的两条关系必须区分 related_name

user（外键）和 users_like（多对多）都指向用户模型。如果不写 related_name，两个反向访问器都叫 image_set，Django 会报冲突。所以这里分别叫 images_created 和 images_liked。

表单：校验 URL，下载图片

import requests
from django import forms
from django.core.files.base import ContentFile
from django.utils.text import slugify

from .models import Image


class ImageCreateForm(forms.ModelForm):
    class Meta:
        model = Image
        fields = ['title', 'url', 'description']
        widgets = {'url': forms.HiddenInput}          # url 由小工具传入，不让用户看到

    def clean_url(self):
        url = self.cleaned_data['url']
        valid_extensions = ['jpg', 'jpeg', 'png']
        extension = url.rsplit('.', 1)[1].lower()
        if extension not in valid_extensions:
            raise forms.ValidationError('The given URL does not match valid image extensions.')
        return url

    def save(self, force_insert=False, force_update=False, commit=True):
        image = super().save(commit=False)
        image_url = self.cleaned_data['url']
        name = slugify(image.title)
        extension = image_url.rsplit('.', 1)[1].lower()
        image_name = f'{name}.{extension}'
        response = requests.get(image_url)            # 下载图片
        image.image.save(image_name, ContentFile(response.content), save=False)
        if commit:
            image.save()
        return image

@login_required
def image_create(request):
    if request.method == 'POST':
        form = ImageCreateForm(data=request.POST)
        if form.is_valid():
            new_image = form.save(commit=False)
            new_image.user = request.user
            new_image.save()
            messages.success(request, 'Image added successfully')
            return redirect(new_image.get_absolute_url())
    else:
        form = ImageCreateForm(data=request.GET)      # 用小工具传来的 GET 参数预填表单
    return render(request, 'images/image/create.html', {'section': 'images', 'form': form})

书签小工具（Bookmarklet）

Bookmarklet 是一个 href 以 javascript: 开头的书签。点它时，代码在当前正在浏览的网页里执行。 问题是书签一旦被拖进书签栏就改不了了，所以采用“启动器”模式：书签里只放几行代码，负责从我们的服务器加载真正的脚本。 

(function(){
  if(!window.bookmarklet) {
    bookmarklet_js = document.body.appendChild(document.createElement('script'));
    bookmarklet_js.src = '//127.0.0.1:8000/static/js/bookmarklet.js?r=' + Math.floor(Math.random()*9999999999999999);
    window.bookmarklet = true;
  }
  else {
    bookmarkletLaunch();       // 已经加载过就直接再次打开浮层
  }
})();

const siteUrl = '//127.0.0.1:8000/';
const minWidth = 250;
const minHeight = 250;

// …加载 CSS、插入 #bookmarklet 浮层…

function bookmarkletLaunch() {
  bookmarklet = document.getElementById('bookmarklet');
  var imagesFound = bookmarklet.querySelector('.images');
  imagesFound.innerHTML = '';
  bookmarklet.style.display = 'block';

  // 找出页面上足够大的 JPEG/PNG 图片
  images = document.querySelectorAll('img[src$=".jpg"], img[src$=".jpeg"], img[src$=".png"]');
  images.forEach(image => {
    if (image.naturalWidth >= minWidth && image.naturalHeight >= minHeight) {
      var imageFound = document.createElement('img');
      imageFound.src = image.src;
      imagesFound.append(imageFound);
    }
  });

  // 点中某张图：打开本站的创建页面，把图片地址和页面标题带过去
  imagesFound.querySelectorAll('img').forEach(image => {
    image.addEventListener('click', function(event){
      bookmarklet.style.display = 'none';
      window.open(siteUrl + 'images/create/?url=' + encodeURIComponent(event.target.src)
                  + '&title=' + encodeURIComponent(document.title), '_blank');
    });
  });
}
bookmarkletLaunch();
⚠ 为什么上一章要折腾 HTTPS

绝大多数网站都是 HTTPS，浏览器禁止在 HTTPS 页面里加载 HTTP 脚本（混合内容）。所以我们的脚本也必须通过 HTTPS 提供。生产环境可以用 Let's Encrypt 免费证书。

用 fetch 实现点赞

点“赞”不需要刷新整页：浏览器用 JavaScript 发一个 POST 请求，服务器返回 JSON，页面局部更新。

from django.http import JsonResponse
from django.views.decorators.http import require_POST


@login_required
@require_POST
def image_like(request):
    image_id = request.POST.get('id')
    action = request.POST.get('action')
    if image_id and action:
        try:
            image = Image.objects.get(id=image_id)
            if action == 'like':
                image.users_like.add(request.user)
            else:
                image.users_like.remove(request.user)
            return JsonResponse({'status': 'ok'})
        except Image.DoesNotExist:
            pass
    return JsonResponse({'status': 'error'})

const url = '{% url "images:like" %}';
var options = {
  method: 'POST',
  headers: {'X-CSRFToken': csrftoken},
  mode: 'same-origin'
}

document.querySelector('a.like').addEventListener('click', function(e){
  e.preventDefault();
  var likeButton = this;
  var formData = new FormData();
  formData.append('id', likeButton.dataset.id);
  formData.append('action', likeButton.dataset.action);
  options['body'] = formData;

  fetch(url, options)
  .then(response => response.json())
  .then(data => {
    if (data['status'] === 'ok') {
      var previousAction = likeButton.dataset.action;
      var action = previousAction === 'like' ? 'unlike' : 'like';
      likeButton.dataset.action = action;
      likeButton.innerHTML = action;
      var likeCount = document.querySelector('span.count .total');
      var totalLikes = parseInt(likeCount.innerHTML);
      likeCount.innerHTML = previousAction === 'like' ? totalLikes + 1 : totalLikes - 1;
    }
  })
});
ⓘ 服务器端模板语言 vs 浏览器端 JavaScript

{% url "images:like" %} 在服务器渲染时就被替换成了 /images/like/；浏览器拿到的是纯 JavaScript。两者运行在不同的地方、不同的时间，别把它们混为一谈。大段脚本更推荐写成独立的 .js 静态文件。

无限滚动

@login_required
def image_list(request):
    images = Image.objects.all()
    paginator = Paginator(images, 8)
    page = request.GET.get('page')
    images_only = request.GET.get('images_only')
    try:
        images = paginator.page(page)
    except PageNotAnInteger:
        images = paginator.page(1)
    except EmptyPage:
        if images_only:
            return HttpResponse('')                 # 告诉前端：没有更多了
        images = paginator.page(paginator.num_pages)
    if images_only:
        return render(request, 'images/image/list_images.html', {'section': 'images', 'images': images})
    return render(request, 'images/image/list.html', {'section': 'images', 'images': images})

var page = 1;
var emptyPage = false;
var blockRequest = false;

window.addEventListener('scroll', function(e) {
  var margin = document.body.clientHeight - window.innerHeight - 200;
  if (window.pageYOffset > margin && !emptyPage && !blockRequest) {
    blockRequest = true;
    page += 1;
    fetch('?images_only=1&page=' + page)
    .then(response => response.text())
    .then(html => {
      if (html === '') {
        emptyPage = true;
      } else {
        document.getElementById('image-list').insertAdjacentHTML('beforeEnd', html);
        blockRequest = false;
      }
    })
  }
});
window.dispatchEvent(new Event('scroll'));    // 内容不满一屏时也能触发加载

代码点评

🔍 第 6 章代码点评 Chapter06/bookmarks/images

做得好 点赞视图的装饰器组合与 CSRF 处理

@login_required + @require_POST，前端用 X-CSRFToken 头、mode: 'same-origin'，返回 JsonResponse。多对多的 add()/remove() 天然幂等，重复点赞不会产生重复行。

有问题 服务器替用户下载任意 URL：SSRF 与资源耗尽 Chapter06/bookmarks/images/forms.py:36

requests.get(image_url) 由服务器去访问一个用户提供的地址，这是典型的 SSRF（服务器端请求伪造）入口： 用户可以提交 http://169.254.169.254/latest/meta-data/...?.jpg（云主机元数据）或 http://localhost:6379/x.png 这类内网地址。 同时：没有 timeout（对方不响应，工作进程就一直挂着）；没有大小上限（一个 10 GB 的“图片”会被整个读进内存）； 不检查响应状态码和内容类型（404 页面也会被当成图片存下来）。扩展名检查也形同虚设 —— 查询字符串里带 .jpg 就能通过。 

import ipaddress
import socket
from urllib.parse import urlparse

MAX_BYTES = 5 * 1024 * 1024


def _is_public_host(hostname):
    for info in socket.getaddrinfo(hostname, None):
        ip = ipaddress.ip_address(info[4][0])
        if ip.is_private or ip.is_loopback or ip.is_link_local or ip.is_reserved:
            return False
    return True


def download_image(url):
    parsed = urlparse(url)
    if parsed.scheme not in ('http', 'https') or not _is_public_host(parsed.hostname):
        raise forms.ValidationError('URL not allowed.')
    with requests.get(url, timeout=(3, 10), stream=True, allow_redirects=False) as r:
        r.raise_for_status()
        if not r.headers.get('Content-Type', '').startswith('image/'):
            raise forms.ValidationError('Not an image.')
        data = b''
        for chunk in r.iter_content(64 * 1024):
            data += chunk
            if len(data) > MAX_BYTES:
                raise forms.ValidationError('Image too large.')
    return data     # 之后再交给 Pillow 验证确实是图片

另外，下载这种慢操作放在请求里做会阻塞工作进程，更好的做法是交给第 8 章的 Celery 后台任务。

有问题 中文标题会生成空 slug，保存后直接 500 Chapter06/bookmarks/images/models.py:36

slugify('中文标题') 返回空字符串。get_absolute_url() 用空 slug 反向解析 <slug:slug> 会抛 NoReverseMatch， 收藏成功后的重定向就变成了服务器错误。对中文用户这是必现 bug。可以这样修： 

def save(self, *args, **kwargs):
    if not self.slug:
        self.slug = slugify(self.title) or 'image'     # 兜底；或引入 python-slugify 做拼音转写
    super().save(*args, **kwargs)

同理 forms.py 里用 slugify(image.title) 生成的文件名也会变成 .jpg。另外 clean_url 中 url.rsplit('.', 1)[1] 在 URL 不含点时会 IndexError。

建议改进 GET 预填表单应当用 initial images/views.py:30

ImageCreateForm(data=request.GET) 创建的是绑定表单，页面一打开就会把“description 为空”等当成提交错误显示出来（取决于字段是否必填）。只想预填时应当用 ImageCreateForm(initial=request.GET.dict())。

建议改进 点赞接口的输入和状态码

action 不是 like 的任何值都会执行“取消赞”；图片不存在或参数缺失时返回 200 + {"status": "error"}。API 应当用状态码表达结果，前端也应处理失败：

@login_required
@require_POST
def image_like(request):
    action = request.POST.get('action')
    if action not in ('like', 'unlike'):
        return JsonResponse({'status': 'error'}, status=400)
    image = get_object_or_404(Image, pk=request.POST.get('id'))
    if action == 'like':
        image.users_like.add(request.user)
    else:
        image.users_like.remove(request.user)
    return JsonResponse({'status': 'ok', 'likes': image.users_like.count()})

顺便把最新的点赞数返回给前端，就不必在浏览器里“猜”着 ±1 了。

建议改进 详情页的 N+1 查询

点赞用户列表里每个 user.profile.photo 都会触发一次 Profile 查询。可以在视图里预取：

image = get_object_or_404(
    Image.objects.prefetch_related('users_like__profile'), id=id, slug=slug
)

建议改进 bookmarklet 脚本的几个隐患 images/static/js/bookmarklet.js

① body.innerHTML += boxHtml 会让浏览器重新解析整个页面，宿主网页上已绑定的事件监听全部丢失，页面可能直接坏掉，应改为 body.insertAdjacentHTML('beforeend', boxHtml)； ② siteUrl 写死 //127.0.0.1:8000/，上线必须改代码 —— 可以把 JS 也作为模板渲染，用 request.build_absolute_uri 注入； ③ boxHtml、images 等没有声明的变量会成为宿主页面的全局变量，可能覆盖对方的同名变量，应该整个包进一个立即执行函数。

建议改进 模板里的无效 HTML images/templates/images/image/list_images.html:4

片段模板里 <a> 里面又套了一个 <a>，HTML 规范不允许嵌套链接，浏览器会自动“修正”DOM 结构，导致样式和点击区域错乱。删掉外层的 <a> 即可。

补充知识 现代 Django 社区常用 HTMX 做这类交互

点赞、无限滚动这类“服务器返回 HTML 片段、局部替换”的交互，正是 HTMX 的强项，可以几乎不写 JavaScript： <div hx-get="?page=3" hx-trigger="revealed" hx-swap="afterend">。本书的 images_only 参数思路与之一致。 另外为了一个 Cookies.get() 从第三方 CDN 加载 js-cookie 并无必要，可以直接 document.cookie 解析，或在页面里用 {% csrf_token %} 渲染后从 DOM 读取。

小结

  • ManyToManyField 通过中间表实现，related_name 让两端都能方便访问。
  • clean_<field>() 校验单个字段；重写 ModelForm.save() 可以把“保存前的额外处理”封装在表单里。
  • Bookmarklet 用“启动器 + 远程脚本”解决无法更新的问题，必须通过 HTTPS 提供。
  • easy-thumbnails 按需生成并缓存缩略图。
  • fetch() 发 POST 时要带 X-CSRFToken；同一视图可以同时返回整页和片段。
  • 任何“服务器替用户访问 URL”的功能都要防 SSRF、设超时、限大小。
