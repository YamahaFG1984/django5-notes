写给谁

  • 学过 Python 基础，想系统学习 Web 后端的人。每个概念都先讲“为什么需要它”，再讲怎么用。
  • 正在读《Django 5 By Example》的人。每章对应原书一章，可以对照阅读，也可以当复习提纲。
  • 已经会写 Django，想知道“教学代码”和“生产代码”差在哪里的人 —— 直接看每章末尾的点评和附录。
  • 准备开始自己第一个项目的人 —— 先读三篇专题：项目起步、测试、调试与日志，书里没讲、但每个项目第一天就用得上。

准备环境

cd Django-5-By-Example-main/Chapter01
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
cd mysite
python manage.py migrate
python manage.py runserver
💡 关于版本

原书基于 Django 5.0 编写，配套仓库的依赖已指向 Django 5.2（LTS）。笔记里凡是 5.1、5.2 带来的变化（比如 {% querystring %}、LoginRequiredMiddleware、复合主键、shell 自动导入模型），都会在对应章节特别说明。
