第 13 章 · 项目四：在线学习平台

内容管理系统

这一章给讲师做一个 CMS：管理自己的课程、编辑模块、往模块里添加各种类型的内容、拖拽排序。 主角是类视图与 Mixin —— 把“只能操作自己的对象”“自动设置 owner”这些横切逻辑写一次、到处复用； 配角是权限组、Formset 和动态表单。

本章目标

  • 用 Mixin 组合类视图，理解多重继承下的方法解析顺序（MRO）
  • 用组和权限控制访问：LoginRequiredMixin、PermissionRequiredMixin
  • 用 inlineformset_factory 在一个页面编辑多个关联对象
  • 用 modelform_factory 根据 URL 参数动态生成表单
  • 用 HTML5 Sortable + fetch 实现拖拽排序

CMS 的视图全景

用 Mixin 组合类视图

“只能看到/编辑自己的课程”这条规则，列表、创建、编辑、删除四个视图都需要。与其写四遍，不如写成 Mixin：

from django.contrib.auth.mixins import LoginRequiredMixin, PermissionRequiredMixin
from django.urls import reverse_lazy
from django.views.generic.edit import CreateView, DeleteView, UpdateView
from django.views.generic.list import ListView


class OwnerMixin:
    def get_queryset(self):                          # 只查自己的
        qs = super().get_queryset()
        return qs.filter(owner=self.request.user)


class OwnerEditMixin:
    def form_valid(self, form):                      # 保存前自动设置 owner
        form.instance.owner = self.request.user
        return super().form_valid(form)


class OwnerCourseMixin(OwnerMixin, LoginRequiredMixin, PermissionRequiredMixin):
    model = Course
    fields = ['subject', 'title', 'slug', 'overview']
    success_url = reverse_lazy('manage_course_list')


class OwnerCourseEditMixin(OwnerCourseMixin, OwnerEditMixin):
    template_name = 'courses/manage/course/form.html'


class ManageCourseListView(OwnerCourseMixin, ListView):
    template_name = 'courses/manage/course/list.html'
    permission_required = 'courses.view_course'


class CourseCreateView(OwnerCourseEditMixin, CreateView):
    permission_required = 'courses.add_course'


class CourseUpdateView(OwnerCourseEditMixin, UpdateView):
    permission_required = 'courses.change_course'


class CourseDeleteView(OwnerCourseMixin, DeleteView):
    template_name = 'courses/manage/course/delete.html'
    permission_required = 'courses.delete_course'

Formset：一次编辑多个模块

from django.forms.models import inlineformset_factory

from .models import Course, Module

ModuleFormSet = inlineformset_factory(
    Course,                       # 父模型
    Module,                       # 子模型
    fields=['title', 'description'],
    extra=2,                      # 额外显示 2 个空表单用来新增
    can_delete=True,              # 每个表单带一个“删除”复选框
)

from django.views.generic.base import TemplateResponseMixin, View


class CourseModuleUpdateView(TemplateResponseMixin, View):
    template_name = 'courses/manage/module/formset.html'
    course = None

    def get_formset(self, data=None):
        return ModuleFormSet(instance=self.course, data=data)

    def dispatch(self, request, pk):                  # GET 和 POST 都需要课程，放在 dispatch 里取
        self.course = get_object_or_404(Course, id=pk, owner=request.user)
        return super().dispatch(request, pk)

    def get(self, request, *args, **kwargs):
        return self.render_to_response({'course': self.course, 'formset': self.get_formset()})

    def post(self, request, *args, **kwargs):
        formset = self.get_formset(data=request.POST)
        if formset.is_valid():
            formset.save()
            return redirect('manage_course_list')
        return self.render_to_response({'course': self.course, 'formset': formset})

动态表单：一个视图服务四种内容

from django.apps import apps
from django.forms.models import modelform_factory


class ContentCreateUpdateView(TemplateResponseMixin, View):
    module = None
    model = None
    obj = None
    template_name = 'courses/manage/content/form.html'

    def get_model(self, model_name):
        if model_name in ['text', 'video', 'image', 'file']:
            return apps.get_model(app_label='courses', model_name=model_name)
        return None

    def get_form(self, model, *args, **kwargs):
        Form = modelform_factory(model, exclude=['owner', 'order', 'created', 'updated'])
        return Form(*args, **kwargs)

    def dispatch(self, request, module_id, model_name, id=None):
        self.module = get_object_or_404(Module, id=module_id, course__owner=request.user)
        self.model = self.get_model(model_name)
        if id:
            self.obj = get_object_or_404(self.model, id=id, owner=request.user)
        return super().dispatch(request, module_id, model_name, id)

    def get(self, request, module_id, model_name, id=None):
        form = self.get_form(self.model, instance=self.obj)
        return self.render_to_response({'form': form, 'object': self.obj})

    def post(self, request, module_id, model_name, id=None):
        form = self.get_form(self.model, instance=self.obj, data=request.POST, files=request.FILES)
        if form.is_valid():
            obj = form.save(commit=False)
            obj.owner = request.user
            obj.save()
            if not id:
                Content.objects.create(module=self.module, item=obj)
            return redirect('module_content_list', self.module.id)
        return self.render_to_response({'form': form, 'object': self.obj})

from braces.views import CsrfExemptMixin, JsonRequestResponseMixin


class ModuleOrderView(CsrfExemptMixin, JsonRequestResponseMixin, View):
    def post(self, request):
        for id, order in self.request_json.items():
            Module.objects.filter(id=id, course__owner=request.user).update(order=order)
        return self.render_json_response({'saved': 'OK'})

代码点评

🔍 第 13 章代码点评 Chapter13/educa

做得好 用 Mixin 表达横切关注点，查询里始终带 owner

OwnerMixin / OwnerEditMixin 是 CBV Mixin 的教科书用法；模块、内容相关的每个查询都带着 course__owner=request.user，即使拿到别人的 ID 也只会得到 404 —— 这是防止“越权访问（IDOR）”的正确姿势。

有问题 仓库代码的“登出”变成了 GET 链接 Chapter13/educa/courses/templates/base.html:14

第 12 章的 base.html 用的是 POST 表单登出，第 13 章仓库代码却改回了 <a href="{% url "logout" %}">。Django 5.0 起 LogoutView 只接受 POST，点这个链接会得到 405 Method Not Allowed，用户根本退不出去。改回带 {% csrf_token %} 的 POST 表单。

有问题 模块与内容相关的视图没有登录保护

CourseModuleUpdateView、ContentCreateUpdateView、ContentDeleteView、ModuleContentListView 以及两个排序视图都没有 LoginRequiredMixin。 匿名用户访问时，owner=request.user 中的 AnonymousUser 会让查询抛出 TypeError，得到 500 而不是跳转登录页；也没有检查讲师权限。 把它们都加上访问控制（按 Django 文档建议放在最左边）： 

class CourseModuleUpdateView(LoginRequiredMixin, PermissionRequiredMixin,
                             TemplateResponseMixin, View):
    permission_required = 'courses.change_course'
    ...

或者直接启用 Django 5.1 的 LoginRequiredMiddleware（见第 4 章点评），从根本上避免“忘了加”。

有问题 排序接口关闭了 CSRF 保护

CsrfExemptMixin 让任何网站都能以已登录讲师的身份 POST 到 /course/module/order/，打乱他的课程结构（典型 CSRF）。 第 6 章已经演示过正确做法：在 fetch 请求头里带上 X-CSRFToken。这样既不需要 django-braces，也不需要豁免： 

import json

from django.db import transaction
from django.http import JsonResponse


class ModuleOrderView(LoginRequiredMixin, View):
    def post(self, request):
        order_map = {int(k): int(v) for k, v in json.loads(request.body).items()}
        modules = list(Module.objects.filter(id__in=order_map, course__owner=request.user))
        for m in modules:
            m.order = order_map[m.id]
        with transaction.atomic():
            Module.objects.bulk_update(modules, ['order'])     # 一条语句代替 N 条 UPDATE
        return JsonResponse({'saved': 'OK'})

var options = {
  method: 'POST',
  mode: 'same-origin',
  headers: {'X-CSRFToken': '{{ csrf_token }}', 'Content-Type': 'application/json'}
}

建议改进 非法的 model_name 会导致 500 courses/views.py:111

get_model() 对未知名称返回 None，随后 modelform_factory(None, …) 或 get_object_or_404(None, …) 直接崩溃。应在 dispatch 里 if self.model is None: raise Http404。同理，URL 里的 <pk>、<id> 应写成 <int:pk>，否则 /course/abc/edit/ 这类地址也会走到数据库查询。

建议改进 删除内容不是原子的；列表页有 N+1

ContentDeleteView 先删 item 再删 Content，中间失败会留下孤儿；包进 transaction.atomic()，或按第 12 章点评用 GenericRelation 让数据库级联。 content_list.html 对每个 content.item 做一次泛型查询，课程列表里每门课又调用 course.modules.count 和 course.modules.first。可以在视图中 module.contents.prefetch_related('item')，课程列表用 annotate(num_modules=Count('modules'))。

补充知识 关于 exclude 与第三方 Mixin TSD：表单 / 第三方包

TSD 反对在 ModelForm 里用 exclude（新增字段会被自动暴露），本章的动态表单为了兼容四种模型只能这样写，属于有意识的取舍 —— 给内容模型新增字段时要记得检查是否应该出现在表单里。 django-braces 提供的 Mixin 在 Django 自身已有等价物（LoginRequiredMixin、PermissionRequiredMixin、JsonResponse）的情况下价值有限，少一个依赖就少一个升级风险。

小结

  • Mixin 把可复用的行为拆成小块，按 MRO 从左到右组合；每个方法都要调用 super()。
  • 权限格式为 应用.动作_模型；用组批量授权；PermissionRequiredMixin 检查权限。
  • inlineformset_factory 在一个页面增删改一组关联对象，别忘了 management_form。
  • modelform_factory 可以在运行时为任意模型生成表单。
  • 异步请求同样要带 CSRF 令牌；批量更新用 bulk_update。
