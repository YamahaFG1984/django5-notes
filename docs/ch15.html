构建 API

网页之外，手机 App、第三方系统、前端框架都需要以程序方式访问平台数据。这一章用 Django REST framework（DRF） 为 Educa 构建一个 RESTful API：序列化器、通用 API 视图、分页、ViewSet 与路由器、认证与权限、自定义权限，最后用 Requests 写一个客户端脚本调用它。

本章目标

  • 理解 REST 的资源、HTTP 方法与状态码约定
  • 掌握 DRF 的核心组件：序列化器、解析器/渲染器、视图、路由、认证、权限
  • 用 SerializerMethodField、嵌套序列化器、自定义关系字段扩展输出
  • 用 ReadOnlyModelViewSet + @action + Router 组织接口
  • 区分认证（你是谁）与权限（你能做什么），编写 IsEnrolled 权限

REST 是什么

REST 把一切看作资源，用 URL 标识资源，用 HTTP 方法表达动作，用状态码表达结果，通常以 JSON 交换数据：

HTTP 方法URL含义常见状态码
GET/api/courses/列出课程200
GET/api/courses/3/获取一门课程200 / 404
POST/api/courses/新建课程201 / 400
PUT / PATCH/api/courses/3/整体 / 部分更新200 / 400
DELETE/api/courses/3/删除204
POST/api/courses/3/enroll/自定义动作：选课200 / 401 / 403

序列化器

序列化器之于 API，就像 ModelForm 之于网页：定义字段、校验输入、把模型和原生数据互相转换。

from django.db.models import Count
from rest_framework import serializers

from courses.models import Content, Course, Module, Subject


class SubjectSerializer(serializers.ModelSerializer):
    total_courses = serializers.IntegerField()              # 来自视图里 annotate 的字段
    popular_courses = serializers.SerializerMethodField()   # 值由 get_popular_courses() 计算

    def get_popular_courses(self, obj):
        courses = obj.courses.annotate(total_students=Count('students')).order_by('-total_students')[:3]
        return [f'{c.title} ({c.total_students} students)' for c in courses]

    class Meta:
        model = Subject
        fields = ['id', 'title', 'slug', 'total_courses', 'popular_courses']


class ModuleSerializer(serializers.ModelSerializer):
    class Meta:
        model = Module
        fields = ['order', 'title', 'description']


class CourseSerializer(serializers.ModelSerializer):
    modules = ModuleSerializer(many=True, read_only=True)   # 嵌套序列化器
    class Meta:
        model = Course
        fields = ['id', 'subject', 'title', 'slug', 'overview', 'created', 'owner', 'modules']

⚠ DRF 不会替你优化查询

序列化 20 门课程、每门课嵌套模块，如果视图的 queryset 没有 prefetch_related('modules')，就是 1 + 20 条 SQL。SerializerMethodField 里的查询同理（上面的 get_popular_courses 每个学科一条）。

视图、分页、ViewSet 与路由

最初用通用视图 ListAPIView/RetrieveAPIView 写学科的列表和详情，然后合并成 ViewSet：

from rest_framework.pagination import PageNumberPagination


class StandardPagination(PageNumberPagination):
    page_size = 10
    page_size_query_param = 'page_size'     # 允许客户端 ?page_size=20
    max_page_size = 50


class SubjectViewSet(viewsets.ReadOnlyModelViewSet):      # 只读：list + retrieve
    queryset = Subject.objects.annotate(total_courses=Count('courses'))
    serializer_class = SubjectSerializer
    pagination_class = StandardPagination


class CourseViewSet(viewsets.ReadOnlyModelViewSet):
    queryset = Course.objects.prefetch_related('modules')
    serializer_class = CourseSerializer
    pagination_class = StandardPagination

认证与权限

from rest_framework.permissions import BasePermission


class IsEnrolled(BasePermission):
    def has_object_permission(self, request, view, obj):     # obj 是 Course
        return obj.students.filter(id=request.user.id).exists()

from rest_framework.authentication import BasicAuthentication
from rest_framework.decorators import action
from rest_framework.permissions import IsAuthenticated
from rest_framework.response import Response


class CourseViewSet(viewsets.ReadOnlyModelViewSet):
    # ...
    @action(detail=True, methods=['post'],
            authentication_classes=[BasicAuthentication],
            permission_classes=[IsAuthenticated])
    def enroll(self, request, *args, **kwargs):
        course = self.get_object()
        course.students.add(request.user)
        return Response({'enrolled': True})

    @action(detail=True, methods=['get'],
            serializer_class=CourseWithContentsSerializer,
            authentication_classes=[BasicAuthentication],
            permission_classes=[IsAuthenticated, IsEnrolled])
    def contents(self, request, *args, **kwargs):
        return self.retrieve(request, *args, **kwargs)      # 复用 retrieve，只是换了序列化器

序列化课程内容

内容是泛型外键，书里用一个自定义关系字段直接调用上一章的 render() 输出 HTML：

class ItemRelatedField(serializers.RelatedField):
    def to_representation(self, value):
        return value.render()


class ContentSerializer(serializers.ModelSerializer):
    item = ItemRelatedField(read_only=True)
    class Meta:
        model = Content
        fields = ['order', 'item']


class ModuleWithContentsSerializer(serializers.ModelSerializer):
    contents = ContentSerializer(many=True)
    class Meta:
        model = Module
        fields = ['order', 'title', 'description', 'contents']


class CourseWithContentsSerializer(serializers.ModelSerializer):
    modules = ModuleWithContentsSerializer(many=True)
    class Meta:
        model = Course
        fields = ['id', 'subject', 'title', 'slug', 'overview', 'created', 'owner', 'modules']

用 Requests 调用 API

import requests

username = ''
password = ''
base_url = 'http://127.0.0.1:8000/api/'
url = f'{base_url}courses/'
available_courses = []

while url is not None:                     # 沿着 next 链接翻完所有页
    print(f'Loading courses from {url}')
    r = requests.get(url)
    response = r.json()
    url = response['next']
    courses = response['results']
    available_courses += [course['title'] for course in courses]

print(f'Available courses: {", ".join(available_courses)}')

for course in courses:
    r = requests.post(f'{base_url}courses/{course["id"]}/enroll/', auth=(username, password))
    if r.status_code == 200:
        print(f'Successfully enrolled in {course["title"]}')

代码点评

🔍 第 15 章代码点评 Chapter15/educa/courses/api、Chapter15/api_examples

做得好 API 代码独立成 api/ 包，只读 ViewSet + 预取

把序列化器、视图、权限、分页、URL 都放在 courses/api/ 下，与网页视图分开，是 TSD 推荐的组织方式；ReadOnlyModelViewSet 不暴露写接口；CourseViewSet 的 queryset 带了 prefetch_related('modules')；自定义权限只做一件事，易于测试。

有问题 客户端脚本只给最后一页的课程选课 Chapter15/api_examples/enroll_all.py

courses 变量在 while 循环里每页都被覆盖，循环结束时只剩最后一页的数据；课程超过 10 门（一页）时，前面几页的课程都不会被选上。应在翻页时累积完整的课程列表，或者在每页内就完成选课。另外账号密码写在源码里，应改为从环境变量读取。

all_courses = []
while url:
    data = requests.get(url, timeout=10).json()
    all_courses += data['results']
    url = data['next']

for course in all_courses:
    ...

有问题 contents 接口的查询数量随内容线性增长

CourseWithContentsSerializer 对每个模块查一次 contents，对每个内容再做一次泛型外键查询，还要各渲染一个模板。一门 10 个模块、每模块 10 个内容的课程就是上百条 SQL。 自定义动作可以覆盖 queryset： 

@action(detail=True, methods=['get'], serializer_class=CourseWithContentsSerializer,
        permission_classes=[IsAuthenticated, IsEnrolled])
def contents(self, request, *args, **kwargs):
    self.queryset = Course.objects.prefetch_related('modules__contents__item')
    return self.retrieve(request, *args, **kwargs)

设计上也值得商榷：API 返回的是一段段 HTML（render() 的结果），移动端或前端框架很难使用。更“API 化”的做法是按内容类型输出结构化数据（{"type": "video", "url": …}），把展示留给客户端。

建议改进 生产 API 不要只用 Basic 认证 TSD：REST API

Basic 认证每次请求都携带明文可解码的密码，必须全程 HTTPS，而且无法单独吊销；它还没有限流保护，是暴力破解的好靶子。 常见组合是：给自家网页前端用 SessionAuthentication（自动带 CSRF 校验），给移动端/第三方用令牌（DRF 的 TokenAuthentication 或 djangorestframework-simplejwt）。 认证类最好在 REST_FRAMEWORK 全局设置里统一配置，而不是写在每个 @action 上。同时开启限流： 

REST_FRAMEWORK = {
    'DEFAULT_AUTHENTICATION_CLASSES': [
        'rest_framework.authentication.SessionAuthentication',
        'rest_framework.authentication.TokenAuthentication',
    ],
    'DEFAULT_PERMISSION_CLASSES': [
        'rest_framework.permissions.DjangoModelPermissionsOrAnonReadOnly',
    ],
    'DEFAULT_PAGINATION_CLASS': 'courses.api.pagination.StandardPagination',
    'PAGE_SIZE': 10,
    'DEFAULT_THROTTLE_CLASSES': [
        'rest_framework.throttling.AnonRateThrottle',
        'rest_framework.throttling.UserRateThrottle',
    ],
    'DEFAULT_THROTTLE_RATES': {'anon': '100/hour', 'user': '1000/hour'},
}

建议改进 版本化、文档与测试 TSD：REST API

API 一旦被外部使用就很难改。TSD 建议从第一天起给 URL 加版本（/api/v1/，或 DRF 的 URLPathVersioning）； 用 drf-spectacular 自动生成 OpenAPI 文档与 Swagger UI；并为每个端点写测试 —— DRF 提供了 APITestCase 和 APIClient： 

from django.contrib.auth import get_user_model
from django.urls import reverse
from rest_framework.test import APITestCase


class EnrollAPITests(APITestCase):
    def setUp(self):
        self.user = get_user_model().objects.create_user('stu', password='pw-12345!')
        self.course = make_course()          # 用 factory_boy 或辅助函数创建

    def test_enroll_requires_auth(self):
        url = reverse('api:course-enroll', args=[self.course.pk])
        self.assertEqual(self.client.post(url).status_code, 401)

    def test_contents_forbidden_if_not_enrolled(self):
        self.client.force_authenticate(self.user)
        url = reverse('api:course-contents', args=[self.course.pk])
        self.assertEqual(self.client.get(url).status_code, 403)

补充知识 SerializerMethodField 的 N+1

学科列表每一项都会执行一次“最受欢迎课程”查询（书中也提到了）。数据量大时可以在视图里用 Prefetch('courses', queryset=Course.objects.annotate(total_students=Count('students')).order_by('-total_students')) 预取，再在 Python 中切片取前三；或者把这类统计结果缓存起来（第 14 章）。

小结

  • REST 用 URL 表示资源、用 HTTP 方法表示动作、用状态码表示结果。
  • DRF 的请求依次经过认证、权限、限流、视图、序列化器、渲染器。
  • 序列化器可以用额外字段、方法字段、嵌套序列化器和自定义关系字段扩展。
  • ViewSet + Router 自动生成 URL；@action 添加自定义端点。
  • 认证确定身份（401），权限决定能否访问（403）；对象级权限通过 has_object_permission 实现。
